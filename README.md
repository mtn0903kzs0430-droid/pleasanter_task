# プリザンター タスク管理・Excel集計サンプル（公開準備中）

日次の予定・実績記録からExcelでの調整・帳票作成までを紹介するブログ用サンプル。

- [Excel v1.2](excel/Pleasanter_作業時間集計_sample_v1.2.xlsm)：利用者がコメントと色を編集したサンプル。ダミー明細を含みます。
- [タスク管理プリザンター詳細仕様書](docs/タスク管理プリザンター_仕様書_v1.0.xlsx)：22シート構成。利用者が権限シートを非表示にした版。
- [一式の概要仕様書](docs/仕様書.md)
- [詳細仕様書の補足](docs/詳細仕様書について.md)と、スクリプト・CSS原文の付録を収録。

ブログ下書き、実業務用の元ブック、バックアップ、過去版、内部検証ファイルは収録しない。

## 初回利用時

1. JSONは既存サイトの上書き用ではありません。テスト用の場所へインポートし、生成されたサイトID・リンク先・スクリプトの参照先を確認します。
2. ExcelのサイトID・取引先IDを実環境に合わせます。API接続先と取引先マスタのサイトIDはVBAに設定があります。
3. Windowsユーザー環境変数 `PLEASANTER_API_KEY` に自分のAPIキーを設定し、Excelを開き直します。APIキーの実値は収録していません。
4. 仕様書の接続設定・取得条件を確認してからテストします。

## 公開準備中の注意

現在は非公開リポジトリで準備中です。新規環境へのインポートからExcel取得までの通し検証は未実施です。最新JSONのタスク管理IDは9664です。インポート後のIDや接続条件は利用する環境に合わせて確認してください。

Excelのコメント・色分けの最終整合確認、および埋め込みVBAと外部ソースの一致確認が残っています。特に水色の報告書提出先は自動転記で上書きされ、請求日・入金期日は期間変更時のみ初期設定されます。

データ再取得では調整時間・メモが消去され、帳票再作成では報告書の手修正が置き換わります。バックアップを確保して利用してください。
